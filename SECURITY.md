# Security and privacy reporting

CycleSync handles intimate health information and sends control messages to
embedded hardware. Please report vulnerabilities privately through GitHub's
**Report a vulnerability** feature rather than opening a public issue.

Useful reports include:

- bypasses of user confirmation or safety limits;
- replay, spoofing, or unauthorized BLE control;
- exposure of menstrual, pain, or physiological data;
- insecure local storage or exported backups;
- firmware paths that fail open after malformed input or disconnection.

Do not include real user health data in a report. Use synthetic examples and
describe the minimum steps needed to reproduce the issue.
